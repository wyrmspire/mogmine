# Progressive Disclosure Audit

| Screen | Level-one facts | One disclosure boundary | Acceptance check |
|---|---|---|---|
| Today | Next action, session summary, account/risk, sync state | Progress detail and learning context | No decision-critical fact requires opening a second panel. |
| Trade Detail | Chart, entry/exit, initial stop, result R, account and Shield | Stop history, partials, plan-vs-actual, notes | At `390×844`, the chart and essential facts appear before secondary evidence. |
| Review | Queue state, current trade, review action, real/replay mode | Daily context and past sessions | Empty, caught-up, offline and loading states are named. |
| Feed | Scope, filters, session rows and review markers | Mood/stat context | Keyboard focus and row actions remain available without opening a menu. |
| Tools | Archive state, account/risk, backup and sync state | Workspace links and preferences | Local, loading, empty, error and recovery states are explicit. |
| Strategy Lab | Hypothetical label, recipe, data source and run state | Recipe history and backup details | Simulated outputs are never presented as realized trades. |

Decision-critical facts stay at level one. Everything else has one named, reversible disclosure boundary.
