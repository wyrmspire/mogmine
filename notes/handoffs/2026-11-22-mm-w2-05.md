## What is done

1. **Interactive Stop Moves Editor (`components/StopMovesEditor.tsx`):**
   - Self-contained React component `StopMovesEditor` accepting `{ trade: TradeRecord; onChange: (moves: StopMove[]) => void; onSuggestMovedStop?: () => void; className?: string }`.
   - Styled cleanly for `390×844` mobile and desktop using Obsidian theme and CSS variables (`--bg-elevated`, `--bg-inset`, `--text-primary`, `--text-muted`, `--gold-mid`, `--border-subtle`, Invariant 5 compliant with zero hardcoded gold hex).
   - Inset `1px` specular gold highlight on container (`box-shadow: inset 0 1px 0 0 rgba(234, 179, 8, 0.2)`).
   - Enforces `tabular-nums` on all price displays, inputs, point deltas, and ticks.
   - All interactive controls (tick steppers `−`/`+`, "Remove" buttons, datetime pickers, "Now" button, "+ Record Stop Move" button, "+ Moved Stop" suggestion button) meet the `>= 44px` tap target requirement.
   - Supports tick-stepping price adjustments (`CONTRACT_SPECS[trade.symbol].tickSize` or `getTickSize(symbol)`) on existing rows as well as new draft moves.
   - Native `datetime-local` picker with conversion to/from UTC via `toZonedInput` / `fromZonedInput` respecting `usePrefs().timeZone`.
   - Per-row categorization badges with color-blind safe icons and text labels (`▲ Tightened`, `⇄ Breakeven`, `⚠ Widened`, `★ Profit Locked`, `— Unchanged`).
   - Non-destructive suggestion banner when risk is widened (`⚠ Moved Stop (widened)`), suggesting the "Moved Stop" tag per `UX-33` without auto-applying or mutating input data. If already tagged, displays a quiet `✓ Tagged` status badge.

2. **Pure Exported Model & Helpers:**
   - `CONTRACT_SPECS`: Alias to `FUTURES_SPECS` for futures contract specs.
   - `classifyStopMove(priorPrice, movePrice, entryPrice, direction, symbol)`: Pure classification returning `"tightened" | "breakeven" | "widened" | "unchanged"`.
   - `computeStopMoveDelta(...)`: Calculates points, ticks, risk direction, locked profit, and widening flags.
   - `computeStopMoveDeltas(trade, moves)`: Multi-step chronological progression comparing Row 0 to initial stop and Row i to Row i - 1.
   - `detectMovesWidening(trade, moves)`: Selector determining whether any stop move in the sequence increased risk.
   - `getTickSize(symbol)` and `stepPrice(currentPrice, steps, symbol)`: Pure tick arithmetic on futures grid.
   - `addStopMoveItem`, `removeStopMoveItem`, `updateStopMoveItem`: Pure immutable state manipulators with `sanitizeStopMoves` sorting.

3. **Unit Tests (`lib/__tests__/stop-moves-editor.test.ts`):**
   - 9 test suites covering `CONTRACT_SPECS`, `getTickSize`, `stepPrice`, `classifyStopMove` (LONG & SHORT), `computeStopMoveDelta`, `computeStopMoveDeltas`, `detectMovesWidening`, `addStopMoveItem`/`removeStopMoveItem`/`updateStopMoveItem`, and `StopMovesEditor` exports.
