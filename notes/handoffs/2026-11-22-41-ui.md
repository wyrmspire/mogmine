## What is done

1. **Trade Card sheet controls (`components/TradeCardSheet.tsx`):**
   - Format picker segmented buttons for `4:5` (standard), `9:16` (story/lock screen), `1:1` (square).
   - Face toggle segmented buttons for `Front` and `Back`.
   - Responsive `TradeCardPreview` updating object URLs when blob changes and applying CSS aspect-ratio matching the selected format.
   - Size and face-aware export filename generation via `shareCardFileName(trade, size, side)`.
2. **Back side canvas painter (`lib/shareCard.ts`):**
   - `renderCardCanvas` renders the card back into `layout.main`: pre-trade thesis, in-trade management notes, post-exit notes, and playbook checklist.
   - Retains 1px gold specular top highlight, carbon hairline border, tabular stats row, and footer.
   - Header indicates `BACK` and retains `SHIELD` badge under privacy mode.
3. **Detail screen wiring (`components/TradeDetail.tsx`):**
   - State for `cardSize` and `cardSide`.
   - Trade Card opens with Shield privacy on by default per `OD-46` (a) and UX-71.
   - Controls wired to `encodeCard` and `buildShareCard` so selecting format or flipping side immediately rebuilds preview.
4. **Mobile styling (`app/globals.css`):**
   - `.trade-card-controls`, `.trade-card-sizes`, and `.trade-card-sides` with >= 44px touch targets.
   - Checked against 390×844 mobile viewport with 0 overflow.
5. **Test coverage (`lib/__tests__/card-system.test.ts`):**
   - Added unit test suites verifying back-side filename formatting (`-back` suffix) and back-side canvas rendering across all 3 aspect ratios.
