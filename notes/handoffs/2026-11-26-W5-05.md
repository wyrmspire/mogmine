# Handoff — Wave 5 Lane 5: Review Tab Overhaul (Zero Demo Flood + Daily | Queue Split)

## Summary of Changes

1. **Excluded demo/sample trades from the default Review Queue (`lib/day-counts.ts`, `components/ReviewScreen.tsx`):**
   - Added `pendingReviewTrades(trades)`, `pendingReviewCount(trades)`, `reviewQueueCounts(trades)`, and `formatRealReviewQueueSummary(trades)` in `lib/day-counts.ts` (filtering strictly to `!trade.is_sample && trade.review_status !== "reviewed"`) while keeping `dayTradeCounts`, `formatDayTradeHeader`, and `formatReviewQueueSummary` backwards-compatible.
   - Updated `ReviewScreen.tsx` so the Review Queue only reads `realPending` by default and never floods the queue or pending summary with the 10 demo fixtures.
   - When the trader has `0` real trades total (`!hasRealTrades`), the Queue tab renders the calm empty state (`"No real trades to review yet — log a trade with + or start a Pretend / Replay session."`) plus an opt-in `"Preview demo queue"` button (`"Exit demo preview"` exits; adding a real trade exits automatically).

2. **Clean 2-Tab Split on `/review`: `Queue (N)` | `Daily` (`components/ReviewScreen.tsx`, `components/PastSessionReviews.tsx`):**
   - Added an accessible segmented tab bar (`role="tablist"`, `seg-tabs` / `seg-tab`, `minHeight: 44`, `minWidth: 44`) switching between:
     - **`Queue (N)`**: Real unreviewed trades one-by-one, day filter chips, `<ReviewChart />`, `<PitStop compact />`, Skip / Full chart / Reviewed actions, and Blind review switch.
     - **`Daily`**: 14-day `DaysStrip`, 1-tap `DailyReviewCta` (counting real trades on the focused day), and `<PastSessionReviews />`.
   - Defaults to `"queue"` when `realPending.length > 0`, otherwise `"daily"`.
   - Updated `PastSessionReviews.tsx` to enforce `44px` tap targets on plan chips and exclude sample trades once real trades exist via `shouldShowSamples`.

3. **Auto-hide demo samples helper (`lib/prefs.ts`):**
   - Exported `shouldShowSamples(prefsShowSamples, hasRealTrades, userExplicitlySet = false)` while preserving `DEFAULT_PREFS` in `lib/prefs-sanitize.ts` and all existing exports including `getTuneRiskBudgetDisplay`.
