# Handoff — Shield sweep (#15) — lane `claude`

- **Issue:** #15. Board row 10. **Branch:** none (shared local folder). No code changed.
- **Status:** sweep done. No leak found. One related data bug filed as `UX-e`.

## How

- Headless Chrome 390×844 against the dev server on :3000, with `shield: true` and `showSamples: true`.
- A script walked every visible text node and every `title` / `aria-label` on Today, Feed, Review, Tune, Drills, Playbooks and Trade Detail, looking for `$<digit>`, `USD`, `contract(s)`, `N×`, `balance`, `qty` and `quantity`.
- Then a code read of every `formatMoney` / `formatBalance` / `formatCents` / `formatUsdAmount` call in the account, challenge, add-trade and close-trade components.

## Result

- `<html data-shield="on">`. The only hits were the word "balance" in prose: the account card's explanation, Tune's Shield caption, and a sample trade's thesis ("under the afternoon balance"). No dollar amount, size or account balance was visible.
- The code checks Shield at every money call site: AccountCard, ChallengeCard, ChallengeDetail, and AddTradeSheet's risk and result preview. CloseTradeSheet shows no money.
- File names: `shareCardFileName` and `playbookCardFileName` carry no result, size or account (tested in `card-system` and `playbook-card-image` tests).
- Canvas text such as the chart pill and the Trade Card is not in the DOM. It is covered by the Trade Card Shield tests and the CD-3c tests.

## Left as is (judgement)

- `ChallengeSetupSheet` repeats the dollar loss limit in its rule sentence under Shield. That is the form where the trader types that amount, so hiding the echo of their own input would confuse more than it protects.

## Found: `UX-e` (board row 12e)

- Under Shield the add-trade form hides the **Contracts** input (`AddTradeSheet.tsx` ~377) and saves the last draft quantity, or 1.
- A 3-lot trade logged with Shield on is stored as 1 contract, so its dollar P&L and every account running total are wrong, silently.
- Fix proposal: keep the input under Shield but masked, for example shown as `•` until focused, or with "hidden on screen, still saved" beside it.
- Not fixed here because `AddTradeSheet.tsx` is in Antigravity's open G1.

#15 can be closed once `UX-e` is fixed.
