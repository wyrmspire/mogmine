## Changes

1. **4-Field Notes Contract, `stop_moves` & R Clarifications (`lib/agent/house-rules.ts`, `lib/agent/openapi.ts`)**
   - `HR-1` and `components.schemas.TradeRecord` now spell out the four distinct note roles:
     - `note`: short 1-line Pit Stop takeaway on cards/feed (optional; never duplicate `pre_trade_thesis`).
     - `pre_trade_thesis`: pre-entry reasoning before entry.
     - `management_notes`: in-trade decisions (holds, trails, scratches, hesitation).
     - `post_exit_notes`: post-exit reflection/lesson (never `"Exit reason: ..."`, prices, contracts, or R).
   - `HR-4` and `TradeRecord.stop_moves` / `/checks/trade` clarify timed `[{ price, time }]` vs leaving `stop_moves` empty with `initial_stop_price` + `stop_loss_price` when the exact move minute is unknown (`"untimed"`), instead of fabricating exit-time moves.
   - `HR-6` and `TradeRecord.stated_risk_r` / `/checks/trade` clarify that `$300` (`r_size_cents = 30000`) is the owner's standard at-least R unit and whole-micro ceiling rounding up by `< 1` micro over target is expected.
   - Kept `HOUSE_RULES_VERSION` unchanged at `"2026-11-26.1"` so existing assertions in `lib/__tests__/agent-api.test.ts` remain aligned.

2. **Non-Blocking Write-Time Warnings (`lib/agent/write-checks.ts`, `lib/agent/trade-check.ts`)**
   - Added non-blocking warning codes to `AgentWriteWarning["code"]` (no new 422 refusals):
     - `notes_duplicate_thesis`: `note` duplicates `pre_trade_thesis` verbatim.
     - `notes_restate_exit_reason`: `post_exit_notes` starts with `"Exit reason: ..."` or matches `exit_reason`.
     - `stated_risk_missing`: `status === "closed"` and `stated_risk_r == null` on create/close/explicit clear (keeps existing pure update-note tests returning `warnings: []`).
   - Expanded `notes_restate_fields` detection to also catch `.25R` (leading dot), `"X dollars"`, contract counts (`"2 contracts"`, `"2 MES"`, `"qty 2"`, etc.), and triggers `playbook_missing` when `playbook_id` is explicitly cleared on update as well as on create.

3. **Friendlier 404 Hints (`lib/agent/dispatch.ts`, `lib/agent/handle.ts`)**
   - Added `notFoundHint(pathname)` in `dispatch.ts` and wired it into `handleAgentRequest` for 404 responses (still HTTP 404 `not_found`).
   - Points agents from guessed paths (`/records/candles`, `/records/levels`, `/singletons/settings`, `/singletons/preferences`, `/singletons/prompt_library`, etc.) to the real endpoints (`/api/v1/candles`, `/api/v1/levels`, `/api/v1/singletons/prefs`, `GET /api/v1/vocabulary`, `GET /api/v1/guide`) and lists valid collections/singletons.

4. **Separate / Generous Rate Limit for Reads & Pre-Flight Checks (`lib/agent/server-auth.ts`, `lib/agent/handle.ts`, `lib/agent/trade-check.ts`)**
   - Exported separate per-key rate limiters in `server-auth.ts`: `sharedReadLimiter` (`300/min`), `sharedPreflightLimiter` (`300/min`), and `sharedWriteLimiter` (`120/min`), plus `defaultAgentLimiter(method)`.
   - Wired `handle.ts` to use `defaultAgentLimiter(method)` (unless `options.limiter` is passed) and `trade-check.ts` to use `sharedPreflightLimiter`.
   - In `runTradeCheck` (`lib/agent/trade-check.ts`), snapped the 1m candle fetch window to whole-hour boundaries (and filtered returned bars back to `[from, to)`) so checking 10–20 candidate times in one session reuses cached bars instead of hitting the `15/min` upstream Yahoo miss cap.
