## Design notes and deviations

- **Logic comes from PL-1.** The view calls `labView(...)` with `rOf` built from `resultR` and `resolveRSize`. No new model code.
- **Formatting helpers are inside `PlaybookLab.tsx`, not exported.** `node --test` cannot import a `.tsx` file, and the package's writable list has no new `lib/` helper module. So the test checks the copy and gating through `labView` output plus source assertions, the way `a11y-routes.test.ts` does.
- **Map and Gaps are summary panels, not the final views.** Each sits in a marked slot with a `PL-2b:` comment, so PL-2b can swap in `<PlaybookLabMap />` and `<PlaybookLabGaps />`.
- **"Open card" links to `/playbooks`.** The binder opens cards from local state, not from a URL, so there is no deep link to the card.
- **Rate copy differs by surface, as the package asked.** Playbook rows say `n X · need 10 closed for rates`. Tag cards say `not enough for rates yet`.
- **Shield.** The Lab prints counts and R only. There is no currency formatting and no dollar literal in the component (a test checks this).
