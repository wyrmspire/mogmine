- **Feed filters from the URL** (`lib/selectors.ts`): `date`, `account`, `playbook`, `tag` join `status`. `playbook=none`, `account=unassigned` and `tag=no-setup-tag` match the null and no-setup cases that the Lab's Gaps links need.
- **Feed chips** (`components/FeedScreen.tsx`): active filters show as removable 44px chips with a "Clear filters" button. Clear resets the URL. The empty state is keyed off any active filter, not only status.
- **Trading-day navigation on Today** (`components/TodayScreen.tsx`): `‹` and `›` (44px), a native date input capped at today, `?date=YYYY-MM-DD` with `router.push` so back works, and "Viewing … · Back to today". - **Review day chips** (`components/ReviewScreen.tsx`): "All days" plus up to 14 unreviewed session dates, newest first, labelled `Mon 23`. Tagging does not rebuild the queue. Tapping a different chip rebuilds it and resets to position 0. The chip list is frozen when the screen opens, like the queue.

## Deviations and decisions

1. **`parseFilters` shape change breaks one existing assertion** (see "Needs owner/integrator action"). The spec requires explicit nulls for an empty URL, so I followed it.
2. **No daily-review link on Today.** The spec's step 3 asks for `/review/day/${viewedDate}`. That route does not exist yet, and DR-2 builds it. A link now would 404, so I left it out.
3. **Future dates fall back to today.** `?date=2026-12-01` shows today, and `›` is disabled there.
4. **The close banner uses `sessionDate(now − 7h)` as the closed day.** It is visible from 17:00 CT until midnight CT, and only while viewing today. On Friday's close it names Friday, not Monday.
5. **"Last trading day" is relative to the viewed day.** On today it is the same as before.
6. **The Feed account chip shows the account name** through `useAccounts()`. Playbook chips use `playbookName()`, so custom playbooks that are not in the registry show their id.
7. **No UI control adds `date`, `account`, `playbook` or `tag`.** They arrive from URLs (the Lab links, deep links). Chips only remove them.
