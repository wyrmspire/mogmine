# [LB-A] Level labels behind candles, solid alpha token, quieter right edge

Package `LB-A` (swarm-3, Wave 4). No migration in this package.

## What changed

- **LB-1 z-order:** `SessionLevelsPrimitive` pane views are now both `zOrder: "bottom"`. Rays draw, then pills, under candles and wicks.
- **LB-2 alpha:** pill background uses `theme.levelLabelBgAlpha` (from `--level-label-bg-alpha: 0.95`, a new token line in `app/globals.css`, read in `lib/theme.ts`). Was hardcoded `0.82`.
- **LB-3 / OD-55a rightOffset:** `TradeChart` reserves `rightOffset` bars when pills show. It re-applies on draw, zoom (separate range listener), and resize. It is memoised on the offset and restores the visible range after changing the offset, so fitted bars do not move. `tap` mode is not implemented (LB-B1).
- **LB-4 quieter right edge:** rays end at `lastBar + 4px` (`update(..., { lastBarTime })`). Settlement lines (`LevelLine.settlement`, set in `lib/chart-levels.ts`) draw as 1px dotted `levelNeutral` at 0.6 alpha (faint 0.3 kept).
- **Tests:** unit tests cover z-order, the 0.95 token with a 4.5:1 contrast check on classic and blue-orange (values read from `app/globals.css`), settlement tagging, the reserve helper, and paint geometry via a fake canvas context. The Chrome check asserts the same against a real canvas.
