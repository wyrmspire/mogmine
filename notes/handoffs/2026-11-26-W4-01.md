# W4-01: Authoritative Supabase Candle Archive Read Path

Implemented the archive-first candle read path against `public.mogmine_market_candles` with Yahoo Finance fallback and zero upstream rate-limit consumption on archive hits.

## Files changed
- `lib/market-data/archive.ts` (new, 233 lines): server-only archive reader using `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`. Returns `null` when unconfigured/offline or on query failure; matches canonical and provider tickers without cross-instrument fallback (`OD-15`); paginates in 1000-row chunks (`ts asc`); converts `ts` to UTC milliseconds (`Candle.time`); parses `numeric` OHLCV; prefers `databento` on duplicate timestamps; aggregates `1m` bars for `5m`/`15m`/`1h` via `aggregateCandles`; exports `mergeArchiveAndYahoo`.
- `app/api/market-data/route.ts` (191 lines): checks `readArchiveCandles` before Yahoo Finance across day mode, open trades, and closed trades. Returns archive candles immediately with `source` (`"Databento Archive"`, `"Databento + Market Archive"`, or `"Market Archive"`) when the window is covered/anchored, and falls back + merges preferring archive bars for unarchived symbols/edges.
- `lib/agent/candles.ts` (398 lines): adds optional `archive` reader on `CandleLoader` (wired to `readArchiveCandles` in `defaultCandleLoader()`, left optional in `createCandleLoader` so test doubles stay isolated). Archive hits never call `loader.upstream.take(limitKey)`.
- `notes/handoffs/2026-11-26-W4-01.md` (new): this handoff.

## Notes for coordinator
- **Epoch unit**: `Candle.time` across MogMine (`lib/trades.ts`, `yahoo.ts`, `coverage.ts`, `lib/agent/candles.ts`, `TradeChart.tsx`) is UTC milliseconds (not seconds). `archive.ts` outputs `Date.parse(row.ts)` in UTC milliseconds to match.
