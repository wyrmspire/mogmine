# Handoff: #175 Local/mock adapter for the persistence contract

- **Date:** 2026-11-23
- **Lane:** gemini-2
- **Issue:** #175 (`claim/175` lock)
- **Spec:** docs/26 §6 (#175 row), docs/22, `D-012`, `D-009`

## What was built

1. `lib/persistence/local-adapter.ts`: `createLocalAdapter({ kind: "local" | "mock", store, candles })` implements the full `JournalRepositories` from `lib/persistence/contract.ts`.
   - Reads and writes the **same device keys and shapes** the UI stores use (`mogmine-trades-v3`, `mogmine-mood-v1` `.records/.candidates/.registry`, `mogmine-accounts-v1`, `mogmine-calls-v1`, and the rest). No data moves.
   - Every read and write goes through the existing sanitizers (`normalizeTrade`, `sanitizeMoodRecords`, `sanitizeAccounts`, `sanitizePlaybooks`, `sanitizePrefs`, …). Invalid records return `invalid` and write nothing.
   - Unreadable stored JSON returns `invalid` and is never overwritten. Blocked or full storage returns `unavailable` and never throws.
   - Other owners see an empty list / `not_found` and get `forbidden` on writes. `archive`-policy types refuse hard delete.
2. `lib/persistence/select.ts`: `chooseAdapter(NEXT_PUBLIC_PERSISTENCE_ADAPTER)`. Missing, empty, `local/mock` or unknown → `local` (today's behaviour). `mock` → in-memory. `supabase` → stub that answers `unavailable` until #176. `getPersistence()` is the lazy singleton.
3. `lib/__tests__/persistence-contract-suite.ts`: the shared contract suite (11 cases). #176 must run it unchanged.
4. Small export changes: `sanitizePrefs` (`lib/prefs.ts`), `sanitizeCandidates` (`lib/mood-store.ts`).

## Choices made (for the reviewer / owner)

- **UI stores are not rerouted.** The existing `use*` hooks and `*-store.ts` modules are unchanged, so the UI behaves exactly as before. The adapter sits beside them and reads and writes the same keys. Moving the stores onto `getPersistence()` is a follow-up, not part of this slice.
- **Fixture refresh (`applyFixtureRefresh`) and demo merging stay in `lib/store.ts`.** The adapter's trade read does not re-run them. It drops unusable rows and rebuilds derived fields, as `readStored` does.
- **Device `RowMeta`:** `updated_at` is the last write made through this adapter instance, and rows written directly by the UI fall back to the epoch. `expectedUpdatedAt` therefore only guards writes made through the adapter.
- **`candles` put** writes `{ candles, fetchedAt }` without `signature`, so the candle loader treats it as a miss and refetches. It never trusts a cache entry whose signature it cannot verify.
- **No cascade on device.** `cascade_parent` is a database rule for #176. The device adapter deletes only the row it is asked to delete.
- **`prompt_library`** is in memory only (no device key, `docs/26 §4`).
- **Proposed for DECISIONS.md (agents propose, owner decides):** env flag name `NEXT_PUBLIC_PERSISTENCE_ADAPTER` with values `local | mock | supabase`, and "stores move onto the adapter in a later slice".
