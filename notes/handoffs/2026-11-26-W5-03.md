# Handoff: W5-03 — Replay Account Mode, Selector Isolation & Agent Workflow

- **Branch:** `wave5/lane-3-replay-model`
- **Scope:** First-class `replay` account mode for pretend / bar-replay sessions, selector/stats/challenge isolation, command validation, and agent API/workflow documentation.

## Files changed
- `lib/accounts.ts` (298 lines) — Added `AccountMode`, `ACCOUNT_MODES`, `isAccountMode`, `accountMode`, `isReplayAccount`, optional `TradingAccount.mode`, `mode` support in `makeAccount` (default `"eval"`), and `mode` sanitization in `sanitizeAccounts`.
- `lib/accounts-store.ts` (195 lines) — Added `mode` parameter to `addAccount`, `mode` sanitization/preservation in `updateAccount` (leaving existing mode intact when `mode` is omitted/`undefined`), and `sanitizeAccounts` pass-through in backup restore.
- `lib/selectors.ts` (428 lines) — Added `AccountScopeFilter`, `isReplayTrade`, `filterByAccountScope`, and `RunningStatsOptions` (`includeReplay?: boolean`); updated `runningStats` to exclude `replay` trades when `opts?.accounts` is passed unless `includeReplay` is `true` (backwards-compatible when `accounts` is omitted/empty).
- `lib/challenges.ts` (327 lines) — Added `EvaluateChallengeOptions` (`accounts?: readonly Pick<TradingAccount, "id" | "mode">[]`) to `evaluateChallenge` to exclude `replay`-account trades from all-accounts challenges while allowing challenges explicitly scoped to a specific `replay` `account_id`.
- `lib/commands/journal-commands.ts` (449 lines) — Validated optional `mode` via `isAccountMode` in `accountParser` on account create/update (failing closed with `invalid` on non-enum values while defaulting omitted legacy `mode` to `"eval"`).
- `lib/agent/house-rules.ts` (229 lines) — Extended `AgentWorkflow["id"]` and `AGENT_WORKFLOWS` with `"pretend_session"` (historical chart bar times in UTC ISO-8601, commentary-only notes per `HR-1`, `POST /api/v1/checks/trade` + read-back per `HR-2`/`HR-11`, and replay stats/Drawdown Defender isolation). Kept `HOUSE_RULES_VERSION` unchanged at `2026-11-26.1`.
- `lib/agent/openapi.ts` (440 lines) — Added `components.schemas.Account` documenting `Account.mode` (`eval | live | sim | replay`, default `eval`).
