## Deviations from the package prompt (deliberate)

1. The top-up runner and `useBarStoreAutoTopUp` live in `use-lab-persistence.ts`, not `bar-coverage.ts`. Putting them in bar-coverage would create an import cycle with bars.ts, and bars.ts is at its cap.
2. The 30-day Yahoo horizon skip (`now - window.to > 29 days`) applies to `loadSession` as well as top-up. Old windows with no server copy now resolve to `no-data` without a network call.
3. The `useLabPersistence` push path is verified at the repository level (fake client), not through a React render. No renderer is available to the targeted tests.
