# IN-2 handoff: Globex VWAP with small overnight gaps, from session start

Package: `IN-2` (swarm-3, wave 3). Branch `swarm/IN-2`. Decision applied: D-F (`gapPolicy: "globex-tolerant"`).
MIGRATION: none needed.

## What changed

- `lib/session-indicators.ts`: `GapPolicy` type and `gapPolicy` option (default `"complete"`). Gap metrics on the
  anchored window (`missingBars`, `longestGapMin`, `rthMissingBars`) are exposed on `coverage.anchored` with
  `approximate`. Under `globex-tolerant` on a Globex anchor, VWAP draws when missing ≤ 3% of expected bars, longest
  run ≤ 15 min, and `rthMissingBars === 0`. Profile (POC/VAH/VAL) and all other levels stay on strict completeness.
- `lib/chart-indicators.ts`: new `tradeSessionVwapReport` (`points`, `approximate`, `missingBars`, `reason`), with
  `tradeSessionVwap` kept as a wrapper. New `joinSessionBars` merges session and trade bars, deduped by open time
  and sorted, and joins only on the same timeframe.
- `components/useTradeLevels.ts`: one session window from 18:00 ET to min(close, now, rounded to the minute). Levels
  are cut at entry (`bar.time < entryMs`) before `tradeLevelReport`. Returns `sessionCandles` and `sessionTimeframe`.
  The third argument `sessionWanted` lets VWAP load the window with levels off.
- `components/TradeDetail.tsx`: passes `vwapAnchor !== "off"` to the hook, merges session bars, and uses the report.
  The View-menu line shows the `reason`, e.g. `Session VWAP · ≈ 23 min missing overnight`.
- Tests: `lib/__tests__/session-indicators.test.ts` (11/23 pattern, 16-min and 3% rejections, 1 RTH gap rejects
  both anchors, zero gaps exact, cutoff invariance) and `lib/__tests__/chart-indicators.test.ts` (report
  approximate and reason, join helper). The existing RTH coverage assertion gained the new fields.

## Interpretation notes

- `longestGapMin` runs over all expected bars in the anchored window. The prompt says "regular-trading", but the
  11/23 case (12 min overnight) only passes that way.
- `rthMissingBars` counts expected bars from `rthOpen` to `min(rthClose, asOf)`.
- Session bars are not joined when their timeframe differs from the trade's. VWAP then uses only the trade's bars.
- Cache: the today window key changed (`to` was entry, now close or now). Each trade refetches that window once.
