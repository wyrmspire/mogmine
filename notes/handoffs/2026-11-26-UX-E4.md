# UX-E4 — Crisp Trade Card PNG export (>= 2x / card width, 18px export chips)

Spec: `docs/design-2026-11-24/08-visual-quality.md` §2 (F-9), §4.3, §5, §7.3.

## What changed

- **`lib/chart-export.ts`** (new, 54 lines, pure, no imports):
  - `EXPORT_MIN_BITMAP_WIDTH = 1200`.
  - `computeExportDimensions(hostW, hostH, dpr, minBitmapWidth)`: returns host size unchanged when the host is empty or `hostW * dpr >= minBitmapWidth`; otherwise `resize: true` at `clamp(ceil(min / (hostW * max(1, dpr))), 2, 3)`× host size (aspect preserved).
  - `computeSnapshotDrawBox(availX, availY, availW, availH, snapW, snapH)`: aspect-preserving, centred `{dx, dy, dw, dh}`.
- **`components/TradeChart.tsx`**: `screenshot()` now computes `exp`, captures the view (logical range, price auto mode, visible price range), calls `setExportMode(true)` before the `try`, and in `finally` calls `setExportMode(false)`, then restores host size and view, then the existing `paintLevels(l, paint, "tap", livePills)` D-E restore. A module-level `sizeForExport` helper does resize + view restore inside `setProgrammaticRange`. `PositionBoxPrimitive.ts` and `TradeDetail.tsx` are untouched.
- **`lib/shareCard.ts`**: the front-side `drawImage` uses `computeSnapshotDrawBox` (same centre as before) inside `ctx.save()` / `ctx.restore()` with `imageSmoothingEnabled = true` and `imageSmoothingQuality = "high"`.
- **`lib/__tests__/chart-export.test.ts`** (new): sizing examples from the spec, aspect ratio, clamp, pass-through, draw-box, the `renderCardCanvas` smoothing order (via a recording ctx), and the TradeChart export wiring.
- **`lib/__tests__/level-card.test.ts`**: only the D-E `try/finally` regex was loosened (`[\s\S]*?`) so the new `setExportMode` / resize statements can sit in the same block. The assertions still require `takeScreenshot(true, false)` in `try` and `paintLevels(l, paint, "tap", livePills)` in `finally`.

## Dependency on UX-E2 (please read)

`setExportMode` exists only in UX-E2. Its commit `5f45b30` was local-only on `r2/UX-E2` (not pushed, no PR). I fast-forwarded this branch onto it, so **this PR's diff against `main` includes E2's 6 files** (`PositionBoxPrimitive.ts`, `chart-paint.ts`, `position-axis-views.ts`, two tests, and the E2 handoff). Once E2 is merged to `main`, this branch's diff reduces to the UX-E4 files only. Merge E2 first.
