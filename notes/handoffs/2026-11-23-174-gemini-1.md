## Not done / choices
- No UI wiring; UI keeps using its stores. No Supabase, no migrations.
- `candles` is excluded from the command set (shared cache, deferred #70).
- `update` uses optimistic concurrency by default; a device adapter that ignores `expectedUpdatedAt` would make it last-write-wins.
- Prompt library has only a shape check (no sanitizer exists yet).
- Cascade deletes are done by the command layer; the Supabase adapter (#176) may also cascade via foreign keys, which is harmless but should be checked there.
