## Decisions I made inside scope

1. **`derived` shapes.** A list row is `{ ...trade, derived }`. A read is `{ record, meta, derived }`. Derived values are never stored. `derived` is absent when `include=derived` is not set, and for collections other than trades and accounts, where it is ignored.
2. **Filters a collection does not support return 422** (`"session_date is not a filter on accounts."`). They are never silently ignored. Supported filters: trades (`session_date`, `from`, `to`, `account_id`, `playbook_id`) and plans (`session_date`). `daily_reviews` is not in the registry yet. When `DR-1b` adds it, add `daily_reviews: ["session_date"]` to `FILTERS_BY_COLLECTION`.
3. **Filter, then limit.** `listFiltered` reads without the limit when a filter is set and applies `limit` to the matching rows.
4. **Malformed filter values → 422 with a plain message.** `session_date` must be a real `YYYY-MM-DD`. `from` and `to` must be ISO-8601 **with a zone**. A time without a zone is refused, because the server would otherwise guess the zone. `from` after `to` is refused. A blank value counts as absent.
5. **`default_r_size_cents`** comes from `resolveRSize({account_id: null}, [], prefs)`, so it is the same value as the dispatch fallback (prefs, else 25 000). The spec formula gives the same value for any valid prefs.
6. **Account `r_size_source`** is `"account"` when the stored `r_size_cents` is valid, else `"prefs"`. That matches `resolveRSize`, so the vocabulary and the derived block agree.
7. **Derived trades resolve the R size through `resolveRSize`.** A trade saved after D-B has a frozen `r_size_cents`, so its `r_size_source` is `"trade"` even when the account has its own size. That is intended (D-B).
8. **Account derived uses `accountSummary`** with all of the owner's trades and balance checks, and `now` as the request time. Archived accounts are resolved too, so a trade on an archived account still gets its R size.
9. **Playbooks in the vocabulary** come from `commands.list("playbooks", {includeArchived: true})`. Active ones come first, then archived ones (flagged). The store also returns the seed playbooks, so they appear too. That matches the owner's actual list.
