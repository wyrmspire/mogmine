## Choices made (the spec did not cover these)

1. **`time`** is ISO-8601 with a zone. Seconds are floored to the minute. A future minute is refused. The decision bar is the one that closed at that minute (§4.4).
2. **`price`** must be on the MES tick grid (a multiple of 0.25). Otherwise it is refused.
3. **`account_id`** is optional. With no account, R comes from `prefs.riskBudgetUsd`, or $250, the same as the Mark screen with no account selected. An account id that is not yours is a 422.
4. **Shield** (`prefs.shield`) is honoured. The basis and the rows then carry no dollar amounts. Owner decision needed: should agents see dollars when Shield is on?
5. **Bars**: only bars whose minute has closed by now are used. The card reads 12 regular sessions, as the UI does. A session with no bars is excluded, counted, and makes the state `partial`. An upstream failure is an error (429 or 503), never a silently partial card.
6. **Upstream cost**: a cold request makes 12 candle calls. The limit is 15 per key per minute, so two cold marks within one minute can get a 429. Cache hits are free.
7. The response carries a `notice` telling the caller that every number is computed by code and must not be recomputed.
