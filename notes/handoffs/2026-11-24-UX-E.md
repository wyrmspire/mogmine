## Deviations and things to know (please read)

1. **Token object location.** 08 §4.6 names `lib/chart-theme-tokens.ts`, which is not in the §7.2 writable list. Per the owner's "exact writable list" instruction, the object lives in `lib/chart-paint.ts` as `CHART_TOKENS`. No file was created outside the list.
2. **VWAP 1.5 px is not applied.** lightweight-charts' `LineWidth` type is the integer set `1 | 2 | 3 | 4`, so `lineWidth: 1.5` fails `tsc`. VWAP stays at 1 px; only the colour changed (`#e879c6`). `CHART_TOKENS.line.vwapWidth` records the spec value but is not used. Needs an integrator decision if 1.5 px matters.
3. **`scripts/check-position-box.mjs` expectations changed**, not "unchanged" as the package prompt asked. The token change moves the pixel values (plan 0.28 → 0.40, actual now a gradient). Geometry assertions are the same: plan positions, `sameRange`, trail steps, cross and manual-exit text. Changed assertions:
   - `planRisk` / `planProfit` 36 → 51. `opacitySamples` 11 / 46 → 15 / 66.
   - `planBorder` now asserts the dashed edge `[0,163,0]`, not equal to the fill.
   - `actual` 146 → 88 (gradient midpoint). `actualBorder` 146 → 240 (solid edge, not equal to the fill).
   - `sameBar` threshold 100 → 80. `trail.hatch` alpha 0.25 → 0.15 (faint hatch).
   - The shim now loads `lib/chart-paint.ts`, and the stub gets the new keys.
4. **Stop path width.** `trade-marks.ts` (read-only) sets 1.5 px. The painter clamps all hairlines to `min(width, 1.25)`, so the stop path is 1.25 px. The entry line is clamped the same way.
5. **Not implemented (out of UX-E scope, or deferred within it):**
   - Shield min chip width 44 px (§4.3).
   - Chip letter-spacing 0.02em.
   - The `chip-warn` (moved or widened stop) chip. `MarkTone` has no warn tone, so it is not reachable yet.
   - Crosshair dash `[4,4]`: the library default line style is kept.
   - R-ruler styling (`[2,4]` at 0.35, labelMuted): ruler dots currently use the shared `dotted` = `[2,3]` round caps. Gate and styling are for **UX-E2**.
   - Lot envelope (**UX-E3**), crisp export (**UX-E4**).
6. **`ChartTheme` key rename.** `chartGrid` is removed and replaced by `gridH` and `gridV`. The only consumers were `TradeChart.tsx` and `DEFAULT_CARD_THEME`. Eleven new keys are added: `crosshairLabel`, `zoneReward`, `zoneRisk`, `entryLine`, `labelMuted`, `chipReward`, `chipRisk`, `chipNeutral`, `chipWarn`, `chipGhost`, `fontMono`, `fontSans`. `chipWarn` is set but not yet used (point 5).
7. **Plan fills are cut by rectangle subtraction**, not the doc's `ctx.clip("evenodd")` sketch. Overlapping actual lots would reopen a gap under evenodd. The subtraction is exact and tested.
