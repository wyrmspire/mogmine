## Deviation: `/guide` does not go through `handleAgentRequest`

The prompt asks for `/guide` to use `handleAgentRequest`. That wrapper only routes to the journal command layer. Its `AgentRoute` union has no `guide` kind, and `lib/agent/dispatch.ts` and `lib/agent/handle.ts` are outside this package's writable files.

So `app/api/v1/guide/route.ts` repeats the same short pipeline with the same server-auth exports: off switch, `authenticateAgent` (bearer, rate limit, key lookup, read/write scope, owner session), `recordAgentUse` audit, and a catch-all that returns no detail.

Differences from the wrapper:
- The rate limiter is a separate counter (120/min per key on `/guide`, and another 120/min on the other routes).
- Auth behaviour is the same, because it calls the same `authenticateAgent`.

**Out-of-scope change that would remove the duplicate:** add `{ kind: "guide" }` to `AgentRoute` in `lib/agent/dispatch.ts`, return `buildGuidePayload(origin)` for it, and have the route call `handleAgentRequest`. That touches two files outside this package, so I stopped and did not make it.

Test gap: the route handler is not unit-tested with a fake `deps`. Next route files may export only HTTP handlers, so the handler cannot be exported for a test, and the route uses the `@/` alias that the `node --test` files do not import. The 401/403/200 behaviour is covered at the layer the route uses: `requiredScope("GET") === "read"` and `hasScope` in `agent-house-rules.test.ts`, plus the existing `authenticateAgent` tests in `agent-api.test.ts`.

## Other notes

- `vocabulary_url` is advertised in discovery and the guide. `GET /api/v1/vocabulary` is not built here (`API-2a`). Until then the URL returns 404.
- HR-10 names `resultR` and `riskR` as derived fields, per `D-A`. The `?include=derived` read mode that `07` §3.5 describes is not built, so HR-10 says the app returns them once it ships.
- HR-6 says `r_size_cents` lives on the account and explicitly describes its integer-cent units. `RS-1` is present after the integrator rebase, so the field is available on this branch.
- Examples in the rules are generic. No trade ids, journal text or account data appear in `house-rules.ts`, and a test asserts that.
- No spec doc needed editing: behaviour matches `07` §2.
- The 553-line addition is above the general slice target because this assigned package deliberately combines the 12-rule source, four discovery surfaces, the authenticated route, and their regression tests. New production files are 214 and 44 lines; no production file crosses 450 lines and no grandfathered file is touched.
