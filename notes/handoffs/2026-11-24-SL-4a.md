# SL-4a — Strategy Lab LevelBook, levelMap (S5) and structureStop (S6)

Branch: `sl/SL-4a` (from `origin/main` 75b81c5)

## Done

- **LevelBook** (`lib/strategy-lab/levels.ts`): builds the levels a decision bar may see from an in-memory `BarSeries` only. Keys: `pdh`, `pdl`, `pdc` (always `approx`), `onh`, `onl`, `rth_open`, `week_high`, `week_low`, `or_high`, `or_low`, `or_mid`. Every level carries `availableAt`, and `levelBookAt(index, i)` returns only levels with `availableAt ≤ decision time` (bar close). Each unavailable extreme reports why it was withheld (`resolveLevelsAt`).
- **Tolerant extremes (D-F):** a window's pdh/pdl/onh/onl/week are usable when ≤ 3% of its minutes are missing and no gap is longer than 15 minutes. Otherwise withheld. Any missing minute makes the level `approx`.
- **Opening range:** strict (all 15 bars of 09:30–09:44 must be present). Available from 09:45.
- **S5 `levelMap`** (`lib/strategy-lab/skills/levels.ts`): with `level` set, returns signed distance in ticks, points, $/contract and R (÷ fixed account R), plus `touch`. With no level, returns the nearest level above and below and a full signed list in `notes`. The reference price is the Context Card mark when present, otherwise the decision close.
- **S6 `structureStop`** (same file): stop beyond the extreme of the last `lookbackBars` 1m bars, with `ticks` beyond it. Returns stop price, distance in points and ticks, $/contract, `qtyAtRiskR`, actual `riskR`, `oversized`, and `rrTo.<levelKey>` for every level on the target side. Quantity is `floor(riskR × fixed R ÷ $/contract)`, never below one contract. R is never inferred from stop width.
- **Known-at test:** levels at bar i are identical when all later bars are deleted, checked at 09:29, 09:30, 09:44, 10:59, 11:00 and 15:00. Both skills pass the existing `assertNoLookahead` harness.

## Choices made (reversible)

1. **ONH/ONL and RTH open are available from the first RTH bar's close (09:31).** The spec says ONH is absent at 09:29. Using the last overnight bar's close (09:30) would make it present at the 09:29 decision.
2. **Prior-session extremes are available at the prior session's last bar close.**
3. **Week-to-date is not withheld for a gap in the current session.** It is labelled `approx` instead, because the running value is a lower bound. A gap in a *completed* session in the week does withhold it.
4. **`touch` means the bar's [low, high] intersects [level − tol, level + tol].**
5. **The "no level" sentinel for `levelMap.level` is `""`.** It is a declared enum option.
6. **`lookbackMinutes` is 120 for `structureStop`**, which is the param max. Actual read is `lookbackBars`.
7. **`rrTo.*` is declared for all 13 level keys**, so the output list is static. Keys with no level come back `null`.
