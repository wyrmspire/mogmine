## Decisions to review

1. **`accountName` is stored inside the `summary` jsonb.** The spec has no column for it. On the remote path it is written as `summary.accountName` and read back out. `summary` itself holds exactly `{ data, candidates, skips, stats, splits, separators, timeOfDay, ms }`.
2. **Compact runs.** `toPersistedRun` keeps only the summary keys and the compact matches. Overlays and any other bulky field are dropped. Matches are not capped. NaN features are stored as `null`, because JSON cannot hold NaN.
3. **Bar reads when signed out** return `unavailable`, not `unauthenticated`, to match spec §14 for this path. When the adapter is off and no client is injected, the result is `ok(null)`, so the caller falls back to IndexedDB. An injected client skips the adapter gate.
4. **Volume.** `0`, `null`, negative and non-finite volume all map to `null` on `SourceBar` (and `NaN` in `BarSeries`). On archive writes they map to `null` in the integer column. The archive helper drops invalid OHLC rows and collapses duplicate times, last one wins, because one upsert cannot touch the same key twice. It upserts in chunks of 500.
5. **Browser code never writes `mogmine_bars_1m`.** The migration grants the authenticated role select only. The write path takes an injected service_role client and is documented as server-only.
6. **Lazy SDK.** The default Supabase client is loaded with a dynamic import, only when `NEXT_PUBLIC_PERSISTENCE_ADAPTER` is `supabase`. The local lab never loads the SDK.
