# R3-08 handoff — cross-tab storage listeners + archive-on-restore (docs/26 §8.4 #4, #5, #7)

## What changed
- **#7 cross-tab listeners** on `prefs`, `plans`, `drills`, `calls`, `daily-reviews`, `tag-registry`: registered in `hydrate*()`, removed in `reset*ForTests()` (no stacking). Ignores other keys and malformed JSON (keeps this tab's copy). Updates state, notifies subscribers, arms the syncer's `.changed()`.
- **#4 accounts**: `restoreAccounts` keeps accounts the backup omits as `archived: true`, so the push reaches `mogmine_accounts` as archived instead of leaving the server row active.
- **#5 playbooks**: `restorePlaybooks` keeps omitted non-No-Setup playbooks (custom or seed) as `archived: true`. An incoming entry with the same id still wins. No Setup is never archived.
- Accounts and playbooks storage listeners moved into the same `listenForStorage`/`stopListeningForStorage` pattern, so reset removes them too.
- Test file `lib/__tests__/cross-tab-and-archive-restore.test.ts` (new, 314 lines).

## Choices I made
- calls-store has two syncers (`calls`, `dismissals`), so a storage event may arm two debounced pushes. The test asserts `>= 1`.
- Playbook restore archives omitted seeds too (the prompt allowed this), not only custom playbooks.
