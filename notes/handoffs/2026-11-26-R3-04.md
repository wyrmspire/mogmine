# R3-04 handoff: thread RSizeOptions through library R consumers

Branch `r3/R3-04`. Goal: legacy trades (`r_size_cents: null`) resolve against the trade's account R ($300) or `prefs.riskBudgetUsd`, never the $250 `DEFAULT_PREFS` fallback (MOGMINE-BLUEPRINT §2.6).

## What changed

- `lib/selectors.ts`: `groupByDay(trades, opts?)` forwards `opts` to `dayStats`. 447 → 447 lines (in-line edits only).
- `lib/drills.ts`: optional `opts?: RSizeOptions` on `isMiss`, `takeVsPass`, `missesDeck`. Also on `missDueAt`, which `missesDeck` calls. Without it, `missesDeck` would still judge misses at $250 (not in the package spec, but needed for the same fix).
- `lib/playbook-card.ts`: `playbookCardData(..., now, opts?)` passes `opts` to `runningStats` and `takeVsPass`.
- `lib/playbook-binder.ts`: the spec names `binderModel`, but no such function exists. The real function is `binderView(playbooks, trades, drills, now, opts?)`, and I added `opts` to it. I did not rename anything. Test calls use `binderView`.
- `lib/mood.ts` (grandfathered): optional `rSize?: RSizeOptions` on `MoodVectorOptions` and `SimilarTradesOptions`. Both `resolveRSize` call sites use it. Line count **895 → 899 (+4, at the limit)**.
- `lib/describe.ts`: `describeTrade(trade, zone, privacy = false, opts?)` uses `resolveRSize(trade, opts?.accounts, opts?.prefs)`.
- `lib/__tests__/r-size-convergence.test.ts` (new): the $300 account case and the `account_id: null` + `prefs.riskBudgetUsd: 300` case, each checked across all 8 consumers, plus a no-opts control (legacy trade reads +0.60R at $250 when nothing is passed).

No edits to `lib/trades.ts`, `lib/shareCard.ts`, `components/**`, or any other unlisted file.
