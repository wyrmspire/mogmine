# R3-06 handoff: week_high / week_low load Mon to prior session

**Status: WIP.** The feature is in place and its new tests pass. Two existing `agent-levels.test.ts` cases fail, and that file is not in this package's writable list, so I did not edit it.

## What changed
- `lib/chart-levels.ts`: `earlierWeekSessionWindows(sessionDate)` returns the regular sessions of the current week strictly before `previousRegularSessionDate` (Mon/Tue: none; Wed: Mon; Thu: Mon, Tue; Fri: Mon-Wed). `tradeLevelWindows` adds `earlierWeek`. `tradeLevels` and `tradeLevelReport` take an optional 4th argument `earlierWeek`. Only entries on `prior.baseTimeframe` are kept, and they are prepended to the candles. A missing or other-timeframe day stays `not-loaded` and does not affect PDH/PDL/ONH/ONL.
- `components/useTradeLevels.ts`: loads the earlier-week windows in parallel with prior and today. A failed day becomes `null`.
- `lib/agent/levels.ts`: loads each earlier-week window through `loadCandles(..., "1m")`. A failed day is dropped (its week level is withheld), so the request does not fail. Its bars feed only the level extraction. VWAP, the EMA and RTH bars still use the prior+today bars, so their output does not change. `lib/agent/levels.ts` is **404 lines** (cap 440).
- `lib/__tests__/week-levels-loading.test.ts`: new, 6 tests.
